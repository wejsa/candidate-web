# Hoji 브랜드 자산

채용 사이트(candidate-web)의 브랜드 "Hoji" 로고 세트입니다. 방향은 **로워케이스 워드마크 + 인디고 액센트**.

## 파일

| 파일 | 용도 |
|------|------|
| `hoji-wordmark.svg` | 기본 워드마크 (밝은 배경) |
| `hoji-wordmark-reversed.svg` | 반전 (어두운 배경 / 다크모드) |
| `hoji-wordmark-mono.svg` | 단색 (`currentColor` 상속 — 어떤 색이든 가능) |
| `hoji-icon.svg` | 앱 아이콘 / 파비콘 (인디고 타일 + h) |
| `hoji-careers-lockup.svg` | "hoji Careers" 락업 (헤더용) |

## 컬러

| 토큰 | 값 | 용도 |
|------|----|----|
| 브랜드 (indigo-600) | `#4f46e5` | 액센트, 주 액션 |
| 브랜드 hover (indigo-700) | `#4338ca` | hover |
| 브랜드 lite (indigo-300) | `#a5b4fc` | 다크 배경 액센트 |
| 잉크 (slate-900) | `#0f172a` | 워드마크 본문, 텍스트 |

> ⚠️ 인디고를 주 액션 컬러로 쓸 경우, 흰 배경 위 인디고(#4f46e5)는 흰 글씨 대비 약 5.9:1로 WCAG AA(4.5:1)를 통과합니다. 기존 `globals.css`의 대비 검증 방식을 유지하세요.

## 폰트

워드마크는 `Pretendard`(1순위) → `Inter` → system-ui 폴백을 사용합니다. 웹에서 정확히 렌더되려면 Pretendard가 로드되어야 합니다(디자인 리뷰 P0-1 항목).

> 배포·인쇄 등 폰트 비의존 환경이 필요하면, 워드마크 SVG의 `<text>`를 아웃라인(path)으로 변환해 쓰세요.

## 사용 규칙

- 최소 여백: 로고 높이의 1/2 이상.
- "i" 글자의 인디고 액센트는 브랜드 시그니처이므로 임의로 단색화하지 마세요(단, `-mono` 버전 제외).
- 워드마크를 세로로 늘리거나 자간을 바꾸지 마세요.
