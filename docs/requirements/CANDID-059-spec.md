# CANDID-059 — 홈/메타 카피 "세상을 움직인다" 테마 전환

## 개요
홈 랜딩·사이트 메타의 카피를 **"금융"** 중심에서 **"세상을 움직인다"** 느낌으로 전환한다. 사용자 요청: H1 "금융을 움직일" → "세상을 움직일"이 어색하지 않고, 전반적으로 "세상을 움직인다"는 메시지로 통일. 순수 카피 변경(로직/스키마/API/DB 무관).

> CANDID-058에서 도입한 "일상을 잇는 금융 플랫폼" 표현도 본 Task에서 "세상을 움직이는 플랫폼"으로 재조정한다(방향 전환).

## 목적
- 채용 메시지를 특정 도메인("금융")보다 임팩트("세상을 움직인다") 중심으로 포지셔닝.
- 헤드라인·메타·히어로를 일관된 톤으로 통일.
