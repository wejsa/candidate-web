# CANDID-058 — 홈/메타 카피 포괄화: "무인 환전·결제 플랫폼" 문구 교체

## 개요
홈 랜딩과 사이트 메타데이터에 박혀 있는 특정 사업 표현 **"무인 환전·결제 플랫폼"**(및 "무인 환전·결제 키오스크")을 제거하고, 더 포괄적인 **"일상을 잇는 금융 플랫폼"** 톤으로 교체한다. 로직·스키마·API 변경 없는 **순수 카피 변경**.

## 목적
- 특정 제품 카테고리(무인 환전/키오스크)에 고정된 표현이 채용 페이지의 메시지를 좁힌다.
- 기존 H1("함께 금융을 움직일 엔지니어")·가치 카드("금융 인프라")가 이미 "금융"을 포괄어로 사용 → 일관된 상위 개념으로 통일.
- SEO 메타(description/og)도 함께 갱신해 검색·공유 노출 문구를 정리.
