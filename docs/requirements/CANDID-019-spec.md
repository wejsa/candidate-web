# CANDID-019 — 마이페이지: 지원 내역 리스트 + 전형 진행 타임라인

> 소급 작성 문서(CANDID-063). 구현 완료. 요구사항 추적성(DS-07)용 요약·링크.
> **요구사항 SSOT**: PRD [`docs/sample-requirement.md`](../sample-requirement.md) — **US-MY-001 / US-MY-002 (P0)** (§2.4).

## 연관 사용자 스토리
- **US-MY-001**: 로그인 사용자가 지원한 공고 목록을 한눈에 보고 진행 상황을 추적한다.
- **US-MY-002**: 지원자가 지원 건의 단계별 진행 상황을 보고 다음 단계를 준비한다.

## 핵심 요구사항 (PRD 발췌)
- 섹션 구분: **작성 중(Draft)** / **진행 중**(제출 완료, 전형 상태) / **종료**(합격·불합격·철회).
- 카드 표시: 공고명, 제출일, 현재 상태, 상태 변경일. 정렬: 상태 변경일 최신순(기본).
- 타임라인 UI: 단계별 시작/완료 시각. 면접 일정 시 일시·장소(또는 화상 링크)·면접관 안내(이름 노출 정책)·**캘린더(.ics) 다운로드**.
- **점수/평가 코멘트는 절대 노출하지 않음**(내부용).

## 관련 비즈니스 규칙 (CLAUDE.md)
- **BR-APP-08**: 면접 일정 `icsUid`는 `(지원서, 면접단계)`당 결정적 키 `iv-{appId}-{stage}` — 동일 단계 재등록은 **멱등 갱신**. 면접 단계는 `INTERVIEW_1`/`INTERVIEW_2`만.
- **BR-APP-07**: 전형 단계 전이는 허용 그래프로만(점프/역행 금지). `HIRED`/`REJECTED` 종단.
- PII: 응답은 마스킹된 식별 단서만, 평문은 명시 열람에서만.
