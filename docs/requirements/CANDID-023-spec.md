# CANDID-023 — 지원 철회

> 소급 작성 문서(CANDID-063). 구현 완료. 요구사항 추적성(DS-07)용 요약·링크.
> **요구사항 SSOT**: PRD [`docs/sample-requirement.md`](../sample-requirement.md) — **US-MY-003 (P1) 지원 철회** (§2.4).

## 연관 사용자 스토리
**US-MY-003**: 지원자가 진행 중인 지원을 철회하여 정중히 의사 표시한다.

## 핵심 요구사항 (PRD 발췌)
- 철회 사유(선택 입력) 수집.
- 철회 후 동일 공고 재지원: 모집 기간 내 1회 허용 또는 불가(**정책 결정 필요** — PRD §8 미결).
- 철회 시 어드민 측 Slack 알림 발송.

## 관련 비즈니스 규칙 (CLAUDE.md)
- **BR-APP-07**: `WITHDRAWN`은 전이 불가(철회는 종단 처리). 상태+이력+감사 단일 트랜잭션 + `FOR UPDATE` 직렬화.
- **BR-APP-01**: 활성 지원서 1건 제약 기준이 `result != WITHDRAWN` — 철회 후 재지원 시 활성 제약 재적용.
- 외부 호출(Slack)은 트랜잭션 외부 이벤트 발행(**BR-TX-02**).

## 인수 조건
- [x] 철회 → 상태 `WITHDRAWN` + 이력/감사 단일 트랜잭션.
- [x] 철회 사유(선택) 수집.
- [x] 철회 후 활성 지원서 제약 재적용(재지원 정책 반영).
